Ecosystem compatibility
=======================

Requests Rust aims to preserve the Requests Python API used by existing
libraries and applications. Compatibility with a package is not implied unless
its behavior has been exercised by this repository's tests.

The broader Requests ecosystem, integrations, articles, and talks belong to
the `upstream Requests project <https://github.com/psf/requests>`_. Report a
rewrite-specific integration difference in the Requests Rust issue tracker
with a minimal reproduction and an upstream comparison.
